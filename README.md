# Weirdest Job Title: Blind Judge Showdown

This entry invents a single job title that sounds just plausible enough to print on a real business card, then ruins it with one absurdly specific detail: the plants are fake, they never needed watering in the first place, and the job covers one floor only. The program validates the title (one line, non-blank, at most 60 characters, no leading or trailing whitespace) and writes it to `entry.txt`.

> Specialist in Watering Fake Plants on the 13th Floor Only

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/jobtitle-out node main.ts
```
